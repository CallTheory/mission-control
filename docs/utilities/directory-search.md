# Directory Search

The Directory Search utility provides a web-based search interface for the Intelligent Series subject directory, allowing you to quickly look up contacts across multiple contact types.

## Supported Contact Types

- **Phone** - Phone number contacts
- **Email** - Email address contacts
- **Fax** - Fax number contacts
- **Vocera** - Vocera badge contacts
- **Cisco** - Cisco phone contacts
- **WCTP** - WCTP pager contacts
- **TAP** - TAP pager contacts
- **Secure Messaging** - Secure messaging contacts
- **SMS** - SMS text message contacts

## Usage

Enter a search term (minimum 3 characters) to search across the IS subject directory. Results are returned from the configured Intelligent Series database connection.

## Setup

Ensure the Intelligent Series database connection is configured in [Datasources](../system/datasources.md).
