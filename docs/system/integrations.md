# Integrations

Used in first-party integrations built directly into the Call Theory Mission Control
application. Integrations are configured at **System → Integrations** and require the
`system.integrations` capability.

> All credentials are stored encrypted in the database. Secret fields are never rendered
> back into the page — leaving one blank keeps the value already stored.

## SendGrid

> Used by the [Inbound Email](../utilities/inbound-email.md) utility.

SendGrid Inbound Parse API

- Choose a subdomain for inbound email, i.e. `inbound-email.yourdomain.com`
- Set up a DNS MX record for the domain pointing at SendGrid
- Use the Destination URL at <https://app.sendgrid.com/settings/parse>
- **Destination URL**: `webhooks/sendgrid/parse/<auto-generated>`
- **Scripting API Key**: &lt;auto-generated&gt;

## Stripe

> Used by the [Card Processing](../utilities/card-processing.md) utility.

- Find your **Testing Secret Key** from Stripe's dashboard and enter it
- Find your **Production Secret Key** from Stripe's dashboard and enter it

## mFax

> Used by the [Cloud Faxing](../utilities/cloud-faxing.md) utility.

mFax Enterprise cloud fax for regulated industries.

Minimum required setup:

- Create a new API-only account with mFax by Documo
- Generate an API key to be used
- Enter the **mFax API key** into the field

If using an mFax Cover Page:

- Get the Cover Page ID you want to use (try *Copy ID to clipboard* from your chosen
  Cover Page menu)
- Enter the **mFax Cover Page ID** into the field
- Enter the **Cover Page Sender Name** (required)
- Enter the **Cover Page Subject Line** (required)
- Enter the **Cover Page Notes** into the field (optional)

## RingCentral

> Used by the [Cloud Faxing](../utilities/cloud-faxing.md) utility.

Minimum required setup:

- Create a new RingCentral Fax developer account
- Generate an API client to be used
- Generate a JWT token from user credentials
- Enter the **RingCentral Client ID** into the field
- Enter the **RingCentral Client Secret** into the field
- Enter the **RingCentral JWT Token** into the field
- Enter the **RingCentral API Endpoint** into the field

## Twilio

> Used by the [WCTP Gateway](wctp-gateway.md).

Twilio provides SMS messaging for the WCTP Gateway.

- **Twilio Account SID**: your Twilio account identifier
- **Twilio Auth Token**: your Twilio authentication token
- **Twilio From Number**: the number to send SMS from when a host has no numbers of its own

Inbound requests are authenticated by Twilio's request signature, validated against the
stored auth token. There is nothing extra to configure.

## Bandwidth

> Used by the [WCTP Gateway](wctp-gateway.md).

Bandwidth provides SMS messaging for the WCTP Gateway using the v2 Messaging API.

- **Account ID**
- **Application ID** — the messaging application that owns your numbers
- **API Token**
- **API Secret**
- **From Number**

Bandwidth's messaging application has a single callback URL that receives both inbound
messages and delivery receipts. Authenticate it with either HTTP Basic credentials
(**Callback Username** / **Callback Password**) or a shared secret (**Callback Token**).

## Commio

> Used by the [WCTP Gateway](wctp-gateway.md).

Formerly known as thinQ. Commio provides SMS messaging for the WCTP Gateway.

- **Account ID**
- **API Username** — the portal user the token belongs to
- **API Token**
- **From Number**

The Commio portal takes a plain URL with no auth options, so authenticate inbound
requests with a shared secret (**Callback Token**) presented as `?token=...` on the URL or
as an `X-Callback-Token` header.

## PeoplePraise

> Used by the [Board Check](../utilities/board-check.md) utility.

The Board Check utility can upload precision reports via API to PeoplePraise.

- **People Praise Basic Auth User**
- **People Praise Basic Auth Pass**
