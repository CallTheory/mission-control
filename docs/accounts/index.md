# Accounts

The Accounts section provides access to your Intelligent Series client accounts. It
requires the `accounts.view` capability and is not available for personal teams.

## Client List

Browse and search your Intelligent Series client accounts with filtering and sorting options:

- **Client Number** - Filter by account number
- **Client Name** - Search by client name
- **Billing Code** - Filter by billing code
- **Account Setting** - Filter by specific account settings
- **Client Source** - Filter by client source

Results can be sorted by Client Number, Client Name, or Billing Code in ascending or descending order.

Click on any client to view detailed account information.

## Client Detail

The client detail view shows comprehensive information for a single account:

- Account details and settings
- Client sources configuration
- Greetings associated with the account

## Client Greetings

View and manage individual greeting recordings for client accounts.
